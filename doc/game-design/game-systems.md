## 1. 스탯 구조 (MP 삭제, SP 시스템 전환)

| 스탯 | 약자 | 설명 | 비고 |
|------|------|------|------|
| 체력 | HP | 0이 되면 전투 불능 | |
| 공격력 | ATK | 스킬 데미지 기본 계수 | |
| 방어력 | DEF | 받는 피해 감소 | 남궁천은 DEF 비례 딜 |
| 속도 | SPD | 행동 게이지 충전 속도 | 높을수록 먼저 행동 |

| 치명타 피해 | CDM | 치명타 시 추가 배율 | 기본 150% |
| 효과 명중 | EHR | 디버프 적중 확률 보정 | 기본 0% |
| 효과 저항 | ERS | 디버프 저항 확률 보정 | 기본 0% |

## 2. SP 시스템 (기력 + 투기 이원화)

### 2-1. 자원 정의

| 자원 | 범위 | 최대치 | 초기값 | 설명 |
|------|------|--------|--------|------|
| 기력(氣力) | 파티 공용 | 5 | 3 | 전투 스킬 사용에 필요한 공용 자원 |
| 투기(鬪氣) | 캐릭터 개인 | 6 | 0 | 궁극기/합벽기에 소모되는 개인 게이지 |

### 2-2. 행동별 자원 변동

| 행동 | 기력 변동 | 투기 변동 | 비고 |
|------|----------|----------|------|
| 평타 | +1 | +1 | 안정적 축적 |
| 전투 스킬 | -1 | +2 | 빠른 빌드업, 기력 소모 |
| 궁극기 | 0 | -6 | 풀 소모 |
| 메인 합벽기 | 0 | -6 (×2명) | 두 캐릭터 모두 풀 소모 |
| 서브 합벽기 | 0 | -4 (×2명) | 코스트 할인 |

### 2-3. 캐릭터별 투기 보너스

| 캐릭터 | 보너스 조건 | 투기 추가 |
|--------|-----------|----------|
| 남궁천 | 피격 시 | +1 |
| 남궁설화 | 디버프 적중 시 | +1 |
| 팽아린 | 치명타 발생 시 | +1 |
| 당소소 | 적 처치 시 | +2 |
| 황보위 | 반격 발동 시 | +1 |

### 2-4. 투기 오버플로우 처리
- 투기가 6(MAX)인 상태에서 추가 투기 획득 시 → 초과분 1당 기력 +1로 변환
- 기력도 5(MAX)면 → 소멸 (아끼는 플레이 유도)

## 3. 데미지 공식

```
기본 데미지 = 스케일링_스탯 × 스킬배율
방어 감소율 = 적_DEF / (적_DEF + 200)
최종 데미지 = 기본 데미지 × (1 - 방어감소율) × 속성보정

※ 치명타 발생 시: 최종 데미지 × (CDM / 100)
※ 방어력 비례 스킬: 스케일링_스탯 = DEF (남궁천 전용)
※ 일반 스킬: 스케일링_스탯 = ATK
```

### 속성 보정 (오행 상성)

**상극 관계:** 금(金) → 목(木) → 토(土) → 수(水) → 화(火) → 금(金)

| 관계 | 배율 |
|------|------|
| 상극 (유리) | ×1.3 |
| 피극 (불리) | ×0.7 |
| 동일/무관 | ×1.0 |
| 무(無) | 항상 ×1.0 (상성 초월, 현경급 전용) |

> ※ 뇌전(雷電)은 별도 속성이 아닌 금(金) 속성의 상위 표현임 (남궁선 등)

## 5. 성장률 시스템 (스탯 등급)

캐릭터마다 각 스탯에 성장 등급(S/A/B/C/D)이 부여됨.

| 등급 | 레벨당 성장값 | Lv60 도달 시 (Lv1 대비) |
|------|-------------|----------------------|
| S | 기본값 × 0.068 | 약 ×5.0 |
| A | 기본값 × 0.051 | 약 ×4.0 |
| B | 기본값 × 0.034 | 약 ×3.0 |
| C | 기본값 × 0.025 | 약 ×2.5 |
| D | 기본값 × 0.017 | 약 ×2.0 |

> SPD는 별도 공식: 레벨당 고정 +0.2 (전 캐릭터 동일, 장비/버프로 차등)

### 주인공 성장 등급

| 스탯 | 남궁천 (딜탱) | 남궁설화 (디버퍼) |
|------|-------------|----------------|
| HP | A (×4.0) | C (×2.5) |
| ATK | D (×2.0) | D (×2.0) |
| DEF | S (×5.0) | D (×2.0) |
| SPD | +0.2/Lv | +0.2/Lv |
| CRT | 고정 5% | 고정 5% |
| CDM | 고정 150% | 고정 150% |
| EHR | +0.3%/Lv | +0.5%/Lv |
| ERS | +0.2%/Lv | +0.1%/Lv |

### 파트너 성장 등급

| 스탯 | 팽아린 (속도딜러) | 당소소 (암살자) | 황보위 (딜탱) | 남궁현 (방관딜러) |
|------|----------------|---------------|-------------|----------------|
| HP | B (×3.0) | C (×2.5) | A (×4.0) | A (×4.0) |
| ATK | S (×5.0) | S (×5.0) | A (×4.0) | S (×5.0) |
| DEF | D (×2.0) | D (×2.0) | A (×4.0) | B (×3.0) |
| CRT | +0.3%/Lv | +0.2%/Lv | +0.1%/Lv | +0.2%/Lv |

## 6. 경지 돌파 시스템

레벨 캡이 경지에 의해 제한됨. 돌파 시 스탯 보너스 + 패시브 해금.

| 경지 | 레벨 범위 | 돌파 조건 | 돌파 보너스 |
|------|----------|----------|-----------|
| 삼류 (三流) | 1~15 | 없음 (시작) | - |
| 이류 (二流) | 16~25 | 돌파 재화 + 1막 클리어 | 전 스탯 +5% |
| 일류 (一流) | 26~35 | 돌파 재화 + 2막 클리어 | 전 스탯 +5%, 스킬 슬롯 해금 |
| 초일류 (超一流) | 36~45 | 돌파 재화 + 3막 클리어 | 전 스탯 +10%, 궁극기 해금 |
| 화경 (化境) | 46~55 | 돌파 재화 + 4막 클리어 | 전 스탯 +10%, 패시브 강화 |
| 현경 (玄境) | 56~60 | 특수 이벤트 + 5막 클리어 | 전 스탯 +15%, 합벽기 강화 |

## 7. 합벽기 시스템

### 발동 조건
1. 연계 대상 두 캐릭터가 모두 파티에 편성
2. 두 캐릭터 모두 투기 MAX (메인: 6/6, 서브: 4/6 이상)
3. 둘 중 한 명이 궁극기 시전 시 연계 선택지 등장
4. 같은 전투에서 합벽기는 **1회만** 사용 가능

### 합벽기 목록

| 루트 | 조합 | 합벽기명 | 등급 | 투기 코스트 | 효과 |
|------|------|---------|------|-----------|------|
| 천 | 남궁천+팽아린 | 염토쌍무 - 폭염지진 | 메인 | 6+6=12 | 적 전체 (토+화=용암), 3턴 화상, 2턴 속도감소 |
| 천 | 남궁천+황보위 | 강철지벽 | 서브 | 4+4=8 | 아군 전체 초거대 보호막 (방어 합산) |
| 설화 | 설화+당소소 | 빙독쌍련 - 극한독화 | 메인 | 6+6=12 | 적 전체 확정빙결 1턴 + 해제불가 맹독 3턴 |
| 설화 | 설화+남궁현 | 현빙무영 - 한월장막 | 서브 | 4+4=8 | 적 전체 극딜+빙결+버프제거, HP<30% 시 설화 회복 |

## 8. 추가 시스템 (제안)

### 8-1. 장비 시스템

| 슬롯 | 주요 스탯 | 예시 |
|------|----------|------|
| 무기 | ATK / DEF(천 전용) | 검, 도, 암기, 부채 등 |
| 방어구 | HP, DEF | 갑옷, 도포, 경장 등 |
| 장신구 | CRT, CDM, EHR, ERS | 반지, 패옥, 부적 등 |
| 내공심법 | 속성 강화, 특수 효과 | 무공 비급 장착 (세트 효과) |

**장비 등급:** 범용(회) → 정제(초록) → 상급(파랑) → 명품(보라) → 전설(주황)

### 8-2. 스킬 강화 (무공 수련)

| 스킬 레벨 | 배율 증가 | 필요 재화 |
|----------|----------|----------|
| 1 (기본) | ×1.0 | - |
| 2~5 | +10%씩 | 무공비급(하급) |
| 6~8 | +15%씩 | 무공비급(중급) |
| 9~10 | +20%씩 | 무공비급(상급) + 특수 재화 |

### 8-3. 호감도 시스템

동료와의 호감도가 오르면 합벽기 데미지 보너스 + 스토리 컷씬 해금.

| 호감도 등급 | 보너스 | 해금 컨텐츠 |
|-----------|--------|-----------|
| 인연 1 (지인) | 합벽기 데미지 +0% | 기본 대화 |
| 인연 3 (동료) | 합벽기 데미지 +10% | 사이드 스토리 1 |
| 인연 5 (신뢰) | 합벽기 데미지 +20% | 사이드 스토리 2 |
| 인연 7 (맹우) | 합벽기 데미지 +30% | 전용 장비 해금 |
| 인연 10 (절친) | 합벽기 데미지 +50% | 최종 스토리 + 전용 칭호 |

### 8-4. 진형 시스템 (전위/후위)

| 위치 | 효과 |
|------|------|
| 전위 (앞줄 2명) | 피격 우선, DEF +10%, 근접 스킬 배율 +10% |
| 후위 (뒷줄 2명) | 피격 후순위, 원거리/디버프 스킬 배율 +10% |

→ 천/황보위는 전위, 설화/소소/아린은 후위가 자연스러움
